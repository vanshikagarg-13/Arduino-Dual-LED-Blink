# Arduino Dual LED Blink

This is my beginner Arduino project using two LEDs.

# Components Used
- Arduino Uno
- Red LED
- Green LED
- Breadboard
- Jumper wires

# Connections
- Red LED → D8
- Green LED → D7
- Cathodes → GND

# Working
- Red LED turns ON for 1 second
- Turns OFF
- Green LED turns ON for 1 second
- Repeats continuously
